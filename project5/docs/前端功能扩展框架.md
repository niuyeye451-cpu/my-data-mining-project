## 功能一：顶部导航栏 + 用户认证

### 1.1 后端 API（新增）

| 路由 | 方法 | 说明 |
|---|---|---|
| `/auth/register` | POST | 注册，Body: `{username, password, email, gender}` |
| `/auth/login` | POST | 登录，返回 Set-Cookie |
| `/auth/logout` | POST | 登出，清除 Cookie |

认证方案：用 **HTTP-only Cookie + 服务端 Session**（比旧代码的 Shiro 更简单，适合课程项目），也可降级为**纯前端 localStorage**（无需后端 session 存储）。

### 1.2 模板（新增）

| 文件 | 说明 |
|---|---|
| `app/templates/login.html` | 登录表单（用户名 + 密码 + 注册链接） |
| `app/templates/register.html` | 注册表单（用户名 + 密码 + 邮箱 + 性别） |

### 1.3 base.html 改动

在 `<header>` 中加入导航栏：
```
[🏭 工业商城]                          [👤 用户名 / 登录]
```

- 未登录 → 显示「登录」链接
- 已登录 → 显示用户名 + 「登出」

## 功能二：搜索关键词高亮

### 2.1 后端改动

`app/search.py` 中查询体加入 `highlight`：

```python
body["highlight"] = {
    "fields": {"title": {"fragment_size": 100, "number_of_fragments": 1}},
    "pre_tags": ["<mark>"],
    "post_tags": ["</mark>"]
}
```

返回结果中新增 `highlight` 字段，模板优先使用高亮标题（用 `safe` 过滤器渲染 HTML）。

### 2.2 前端改动

`index.html` 中商品标题改用高亮版本：

```html
{% if p.highlight %}
  {{ p.highlight | safe }}
{% else %}
  {{ p.title }}
{% endif %}
```

CSS 加一行：
```css
mark { background: #FFEB3B; padding: 0 2px; border-radius: 2px; }
```

## 功能三：标签上的商品计数（聚合统计）

### 3.1 后端改动

`app/search.py` 每次搜索时附带 `aggs` 请求：

```python
body["aggs"] = {
    "categories": {"terms": {"field": "catid", "size": 35}},
    "areas":      {"terms": {"field": "parentid", "size": 40}}
}
```

返回结果新增 `cat_counts` 和 `area_counts` 两个字典 `{id: count}`。

### 3.2 前端改动

`index.html` 标签渲染时显示计数：

```
五金制品 (15)
重庆市 (10)
```

逻辑：`cat_counts` 中有的显示数字，没有的显示 0 或省略。
